eBay Buyer Dashboard — Live API

🔌 Connect your eBay Account

  1. Register at developer.ebay.com and create an app to get your App ID, Dev ID, Cert ID
  2. On the same page, click "Get a User Token", sign in with your buyer eBay account, and copy the token
  3. Copy .env.example → .env and paste all four credentials
  4. Run npm install && node server.js — this dashboard will load your real orders automatically
